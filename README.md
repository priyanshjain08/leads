# 🏠 Real Estate Outreach CRM

A lightweight, browser-based **Real Estate Lead Outreach CRM** built with vanilla HTML, CSS, and JavaScript.

It helps you manage real-estate prospects, send personalized WhatsApp outreach messages, track follow-ups, add notes, filter leads, and export your outreach progress — all from a single HTML file.

---

## ✨ Features

### 📋 Lead Management
- Manage **162+ real-estate leads**
- Lead information includes:
  - Business name
  - City
  - Phone number
  - Website
  - Google rating
  - Review count
  - Website issues/opportunities
  - Recommended service offer
  - Personalized outreach message

### 💬 WhatsApp Outreach
Each lead has a **Send on WhatsApp** button.

Clicking it opens WhatsApp with a pre-filled, personalized message for that business.

After sending:
- The lead is automatically marked as **Sent**
- A new lead is automatically moved from `New` → `Contacted`

### 📊 Lead Status Tracking

Track every prospect through the following stages:

| Status | Purpose |
|---|---|
| `New` | Lead has not been contacted |
| `Contacted` | Initial outreach has been sent |
| `Replied` | Prospect has responded |
| `Interested` | Prospect has shown interest |
| `Converted` | Prospect became a customer |
| `Not Interested` | Prospect declined |

Each status is visually highlighted so you can quickly identify your pipeline.
